Design System & CSS Guide

A detailed reference for the SeatStar typography, color palette, and styling conventions. This guide includes HEX codes, font families, and usage details.

Typography

Primary Font / Body Text
Inter
font-family: 'Inter', system-ui, sans-serif;

Used for general user interface elements, body text, buttons, and data display. It is highly legible and functional.

Light Regular Semibold
Secondary Font / Headings
Playfair Display
font-family: 'Playfair Display', Georgia, serif;

Used for H1-H6 headings and elegant accents to give a premium, editorial feel for a B2B chair brand.

Regular Medium Bold

Color Palette

All colors are defined as HSL CSS variables in src/index.css and mapped to Tailwind classes via tailwind.config.js. Both the HEX and HSL source are listed for each token.

Interactive Elements & UI Classes

Premium Button

Use the .btn-premium utility class for primary calls to action. It uses a custom gold/bronze CSS gradient defined in index.css.

Text Gradient

Use the .text-gradient-premium class to clip text with the premium gradient. Beautiful on large headings.
